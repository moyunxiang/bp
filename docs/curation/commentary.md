# 解说视频条目提炼规范

目的：从B站解说视频的字幕里提炼关于英雄克制、配合和BP思路的**具体主张**，作为知识库的补充证据。原始字幕只留在本地 `data/raw/commentary/subtitles/`，**不进仓库、不公开**；进仓库的只有提炼后的简短条目和视频链接。

## 输入

`data/raw/commentary/subtitles/{bvid}.txt`：前两行是标题、UP主、发布日期、链接；之后每行是“分:秒 字幕内容”。字幕是自动识别的，会有错字和同音字（英雄名尤其常见），需要结合上下文判断，判断不了就跳过。

英雄的规范名称见 `data/derived/official/heroes.json` 的 `name` 字段，常见外号见 `data/curated/aliases.json`。

## 输出

对每个视频写一个文件 `data/curated/commentary/{bvid}.json`：

```json
{
  "bvid": "BV1xx411c7mD",
  "title": "视频标题",
  "uploader": "UP主名",
  "date": "2026-10-20",
  "items": [
    { "type": "counter", "a": "盾山", "b": "马可波罗", "claim": "盾山举盾能挡住马可波罗的子弹，马可需要绕到侧面输出", "t": 185 },
    { "type": "synergy", "a": "大乔", "b": "孙策", "claim": "大乔的传送让孙策可以开船后快速回线", "t": 402 },
    { "type": "tip", "a": "东皇太一", "b": null, "claim": "对面有多个位移刺客时，东皇适合后手选", "t": 77 }
  ]
}
```

- `type`：`counter` 表示 `a` 克制 `b`；`synergy` 表示两者配合；`tip` 是针对单个英雄的BP提示（`b` 为 `null`）。
- `a`、`b` 用英雄的规范名称。
- `claim`：用自己的话概括解说的主张，**不要照抄字幕原句**，不超过60个字，要包含“为什么”或“在什么条件下”。
- `t`：解说讲到这一点的时间点（秒），取自字幕行首的时间。

## 取舍标准

只提炼**解说明确说出、并给了理由**的主张。以下内容不要提炼：

- 没有理由的强度判断：“这个英雄很强”“版本答案”“必ban”“T0”。
- 胜率、上分效率之类的说法。
- 出装、铭文、操作细节（连招手法、走位）。
- 只适用于某一局比赛的复盘结论（“这局因为经济落后所以……”）。
- 字幕识别不清、无法确定说的是哪个英雄的内容。
- 你自己知道但解说没有说的内容。**不要补充，不要推理。**

一个视频通常能提炼 3–12 条；没有合适内容就给空的 `items`。同一主张在视频里反复出现只记一条。

## 之后

运行 `npx tsx scripts/commentary/build.ts`。脚本会把英雄名转成ID、丢弃含强度断言的条目，并做自动核实：与已有官方关系或机制规则方向一致、或被两个以上不同UP主提到的条目才会标为已核实并参与计分；其余只在研究模式里以“未核实”展示。
